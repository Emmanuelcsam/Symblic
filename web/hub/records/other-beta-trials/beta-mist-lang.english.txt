The type is exactly one of: number, string, ident, keyword, op, punct, eof. The keywords are exactly: let, fun, return, if, else, while, true, false, and, or, not. Numbers are digit sequences with an optional single decimal point and at least one digit after it; their value is the number itself. Strings are double-quoted with exactly the escapes backslash-quote, backslash-n, backslash-t and double-backslash; their value is the decoded content. A comment runs from two slashes to the end of the line and is skipped entirely. Whitespace separates tokens and is otherwise skipped. Create the file mist-interpreter.js in the folder /srv/symblic/projects/beta-lang defining the single global function runMistProgram(sourceText, outputCallback) that parses the text with parseMist and executes it, calling outputCallback once per printed value rendered to text. The values are numbers, strings, booleans, arrays and null. Rendering is exactly: integers print without a decimal point, non-integers print in shortest decimal form, booleans print as true or false, strings print their content, arrays print as an opening bracket, the elements rendered the same way separated by comma-space, and a closing bracket, and null prints as null. The truth rule is exactly: false and null are falsy, and every other value is truthy. The builtins bound before the program runs are exactly: print with one argument that passes the rendered value to outputCallback and returns null; len with one string or array argument returning its length; push with an array and a value appending the value and returning the same array; pop with an array removing and returning the last element; join with an array and a separator string returning the elements rendered and joined by the separator; str with any value returning its rendering; num with a string or number returning the number. A call to a name that is not a function, a call with the wrong argument count, indexing a non-array, an index outside the array bounds, and arithmetic between a number and a boolean all throw MistError naming the problem and the line.
