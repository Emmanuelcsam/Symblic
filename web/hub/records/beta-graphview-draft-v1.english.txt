The simulation keeps one three-dimensional position, velocity and pinned flag per node; alpha starts at one; initialize creates one node for every note and one ghost node for every unresolved link target, seeds distinct starting positions so no two nodes share a position, and records each node's link count; tick applies a center attraction toward the origin scaled by centerStrength, a spring force along every link toward its rest length linkDistance scaled by linkStrength, a mutual repulsion between every pair of nodes scaled by repelStrength, a separation preventing overlapping nodes scaled by collideStrength, integrates with damping by velocityDecay, decrements alpha by alphaDecay, and returns false without moving anything once alpha is below one one-hundredth; pin fixes a named node's position until unpin frees it; positions returns every node id with its current three-dimensional coordinates, its link count and its pinned flag; pinned nodes never move.
