What the small-model construction test achieved

On 6 October 2026, two builds using the installed llama3.2:1b completed the same thirteen-function parcel program. Each model received one precise instruction, a typed expression menu, its public checks and only its declared accepted dependencies. Optional finite completion checked replacements after a rejected proposal. Both builds produced the same native Symblic file.

The model still made mistakes. Symblic prevented the rejected expressions from becoming accepted work; the engine supplied the replacements under the same authored predicates. These are hybrid results, not thirteen correct model answers or a claim that prompting made Llama infallible. Every model proposal and host trial remains in the private construction records, with distinct origins and exact runtime receipts.

The largest requests were 2,992 and 2,976 characters respectively, counting system text, task prompt and answer schema. These are character counts, not tokens or RAM measurements. Builds used temperature zero, seeds 7 and 17, and the same freshly observed model manifest digest under strict identity policy. This checks observed manifest identity, not loaded-weight attestation. Timing describes these admitted worker node runs, not a general hardware benchmark.

The finished program runs without a model

Both completed files matched all intermediate fields and the aggregate for the same 128 predeclared validation cases: 64 original cases and 64 broader cases, including boundaries. Execution and durable artifact recovery used no additional model calls. The two builds are not 256 different test cases. The broader set was frozen before an earlier expression-only trial and reused here; it was never sent to the model or used to select a construction choice. Passing these finite cases is evidence about this example, not a proof over all inputs.

The saved live dashboard run (recorded on the original host; not public) executes the finished file on the three sample parcels. It returns quotations 80, 173 and 0, total 253, with zero model calls. Use Open program in editor on its Runs view to change the inputs and run it again. The arithmetic uses declared integer dimensions, grams and price units; it is an example policy, not a carrier's tariff.

What was learned before this run

Earlier model-only trials did not complete the thirteen-function program. The retained development record contains 37 real calls across numeric-choice, direct-instruction, expression-choice and primitive-label trials; this final hybrid test adds 26 calls. They are an adaptive development sequence with different representations and budgets, not a matched accuracy comparison.

An offline all-wrong-proposal check also found a weak local tax contract: ceil(amount / denominator) * numerator passed three local examples but failed the public final composition check. The run stopped. We added the already-public subcase sales_tax(74,7,100) = 6 to the local checks, kept every menu choice and preserved the original failed record. No validation case was used for that correction. With the revised local contract, all 39 authored distractors fail locally and all 13 intended expressions pass. Both all-correct and all-wrong simulated builds complete, with model and engine origins kept separate.

What this demonstrates

Symblic can preserve a larger construction while a small model handles bounded individual decisions. The caller supplies the instructions, menus, dependencies, checks and surrounding program. This path supports up to 64 steps and 16 choices per step; it does not automatically turn an arbitrary objective into a complete specification. The finished functions are reusable and need no model to execute.

Finite completion is optional and off by default. It adopts the first locally passing choice; a failed final combined check stops the run without global backtracking. Missing correct candidates, inadequate tests, unavailable providers, malformed answers, exhausted resources and stops remain visible limitations. Models below 1B were not measured in this trial.
