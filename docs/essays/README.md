# Essays: speculative AI writing about Symblic

> **These are not research results.** All fifteen essays were generated in October 2026 by a Gemini model working
> through Google's Antigravity agent, while Symblic was being built. No human expert reviewed them. They present
> analogies (string theory, quantum mechanics, fluid dynamics, philosophy of science) as if they were foundations,
> describe language features that do not exist and cite results nobody checked; their headers credited a "Codex
> Integration Team" that, as far as the records show, took no part. They are kept because they are part of the honest record of how Symblic was
> made. Read [../MADE-WITH-AI.md](../MADE-WITH-AI.md) first.

When the essays were written, another agent reviewed nine of them against the code. Its readers found 63 proposals
and 120 factual errors; 12 proposals were later built in a reduced form and 32 were rejected
([../reference/REVIEW-2.3.md](../reference/REVIEW-2.3.md)). Corrected versions of several essays are in
[../reference/](../reference/README.md); they are still AI-written, but they separate what exists in the code from
analogy.

## What was changed for publication

The essays are otherwise as the agent wrote them, apart from these edits: the author lines, which credited a person
and a "Codex Integration Team", now name the AI that wrote them; a status line and the note at the top were added;
passages that named a person, a private document or the original host's other applications were replaced with neutral
text and marked *Edited for publication* (short mentions of the same private document were removed without a mark,
and two invented install commands were replaced by a note saying so); file paths were updated to this repository's layout. A machine-generated
inventory of the original host's files, which had been saved in the same folder, was removed.
