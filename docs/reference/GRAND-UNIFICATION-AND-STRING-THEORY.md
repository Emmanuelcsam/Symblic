**Status:** this document specifies research admission criteria. It does not define additional language syntax or claim that physical dualities already govern the runtime. Implemented finite algorithms, reform prototypes and proposed experiments are distinguished below. The complete topic-by-topic register remains [RESEARCH-ADOPTION](RESEARCH-ADOPTION.md); this document corrects the earlier asserted unification and explains how its useful research directions can advance.

Mathematics can improve Symblic when it supplies a representation, an algorithm, a theorem with satisfied hypotheses, or a useful experimental model. An attractive correspondence between vocabulary is not enough. A proof about a supplied finite matrix, a fluid field or a formal type does not automatically apply to a language model, a source document or an autonomous workflow.

## The admission rule

For each proposed connection, specify:

1. **Objects:** what are the variables, states, observations, units and domains? Which are measured and which are merely assumed?
2. **Map:** how does the task become those objects, and what information does that mapping lose? Which semantic or physical assumptions does it add?
3. **Construction:** what exact algorithm runs, with what resource limits and arithmetic regime?
4. **Conclusion:** what theorem or checked predicate applies to those objects, under which hypotheses? Does it concern feasibility, optimality, consistency, prediction or reality?
5. **Comparison:** which simpler method gets the same inputs, checkers and budget? What held-out failure would falsify the proposed advantage?
6. **Integration:** how are dependencies, uncertainty, evidence, versioning and refusal represented in the existing runtime?

A connection may be valuable before it proves a grand theory. A bounded optimizer that saves time on a defined workload is useful on those terms. Conversely, passing the repository's syntax tests establishes nothing about a new physical analogy.

## Fluid computation, projection and stability

The earlier document attributed an unrestricted fluid-computation theorem to Tao's averaged Navier–Stokes blow-up paper and then treated it as a stability guarantee for agents. That attribution did not justify the proposed inference. The cited paper constructs finite-time blow-up for an **averaged modification** of the equation and discusses obstacles to regularity arguments; it does not supply Symblic with a token-to-fluid map or a hallucination guarantee. [Tao's original paper](https://arxiv.org/abs/1402.0290)

There are two separate research directions:

- For actual physical simulations, retain the specified equations, units, domain, forcing, initial/boundary conditions and numerical approximation. Stability criteria only apply after their assumptions and numerical relationship have been established.
- For agent systems, define software quantities directly: unresolved dependencies, context loss, resource use, failed checks, stale observations and recovery outcomes. Investigate whether those measurements predict errors on held-out tasks.

A BKM-style regularity criterion cannot be renamed a bound on hallucination. No map from arbitrary model traces to the required fluid quantities is currently specified. The previous `<0.001%` claim is withdrawn, rather than retained as an implied target guaranteed by physics.

Projection remains useful where the task really provides an affine constraint. The existing reconciliation adapter can check the closest feasible point under its metric. Its result must remain a proposed reconciled estimate beside the original observation and movement receipt. A constraint conflict can require refusal; replacing assertion failure with automatic correction would conceal disagreement or change the task.

## Holography and Ryu–Takayanagi

Maldacena's correspondence concerns particular field-theoretic and gravitational constructions. The original Ryu–Takayanagi work relates entanglement entropy and areas in a specified holographic setting. Neither source identifies arbitrary token embeddings with the required physical boundary theory. [Maldacena](https://arxiv.org/abs/hep-th/9711200), [Ryu and Takayanagi](https://arxiv.org/abs/hep-th/0603001)

Symblic currently has no implemented holographic dictionary, gravitational bulk, independently measured cognitive entanglement, or minimal-surface certificate of factual accuracy. Assertions that hallucinations form wormholes or that smooth surfaces verify inference are withdrawn.

A permitted experiment would define a finite representation and a computable geometric score, then compare its held-out error detection with basic confidence, length, retrieval and checker baselines. Preserve the original data, account for fitting and computation cost, and measure false acceptance as well as rejection. If a score is useful, report it as that tested predictor. Calling it holographic requires additional mathematical work establishing the claimed correspondence.

## String worldsheets, conformal symmetry and prompt injection

The previous argument equated an API interaction with a point-particle singularity and assumed conformal smoothing removes attacks. No encoding, theorem hypotheses or authority-preservation proof supported that step. Prompt injection is not defined as a physical ultraviolet divergence, and no Virasoro constraint in the runtime establishes security.

A sequence- or graph-smoothing transform could still be tested as an input-processing experiment. Define exactly which text or graph state it changes, retain the original evidence and compare attack success, legitimate task success, lost exceptions and latency. The authority boundary must remain enforced even when the transform fails. A successful experiment would justify a bounded defense claim under its threat model, not mathematical immunity.

Security research should also preserve the existing untrusted/personal/steered labels, capability catalogue, admitted execution paths and durable effect identities. A smoother representation cannot replace those mechanisms.

## Mirror symmetry, T-duality and representation transport

The earlier “Symblic Mirror Theorem” asserted that arbitrary intractable constraints become instantaneous linear differential equations. There is no such theorem or implementation here. A physical duality is not an all-purpose algorithmic reduction, and translating a representation can move complexity into its encoder, solver or decoder.

The useful finite question is explicit: given representations A and B, provide forward/backward transforms, domains, loss information and predicates to transport. Check round trips where justified and independently check transformed answers in the original representation. Measure total cost, including conversion and expansion.

Likewise, no T-duality currently compresses an arbitrary enterprise program into a tiny prompt with all relevant meaning preserved. Required context is a concrete dependency obligation. If it does not fit the declared budget, the reform reports that limit. Optional source-linked summaries and retrieval are evaluated for their actual task-specific loss.

## HoTT and schema equivalence

An equivalence must be supplied or constructed before it can justify transport. Equal field types or similar names do not identify two business concepts, currencies or entities. Univalence does not discover the intended mapping or make implementation and transport computationally free. [The HoTT book, sections 2.3 and 2.10](https://homotopytypetheory.org/book/)

A useful first adapter would support explicit finite mappings, inverses, units and identifier policies. It would reject lossy coercion and report the predicates whose transport was actually justified. Adversarial tests should include swapped same-typed fields, incompatible units, missing exceptions and a mapping that round-trips structurally while misrepresenting the user's meaning. Full dependent-type or HoTT integration remains a separate language project.

## Sheaves, topoi and consistent perspectives

Cellular sheaves offer explicit mathematical structures for local data and compatibility maps; spectral methods can analyze specified instances. That is a substantive direction for heterogeneous observations, not a license to declare every consensus true. [Hansen and Ghrist](https://arxiv.org/abs/1808.01513)

An experiment must specify local spaces, restriction maps, observations and the exact compatibility question. A global section establishes compatibility relative to those maps, not external truth. A disagreement is not automatically an element of first Čech cohomology. Arbitrary model replies do not supply a sheaf, a common prior, or independent observations merely by coming from different machines.

For operational agent state, a dependency graph plus explicit conflicting claims is the immediate baseline. A more elaborate mathematical model should earn its place by exposing an inconsistency or improving a prediction that this simpler representation misses.

## A concrete path toward a stronger system

The reform first establishes common interfaces: human formal statements, model-produced proofs, exact source witnesses, versioned claim dependencies, typed graph edges, explicit unknown states and complete evaluation denominators. These interfaces make later experiments comparable and let useful adapters compose.

Every future research contribution should include a small reproducible construction, a failure example, a versioned checker where possible, cost accounting and a claim of exactly the measured scope. Negative results belong in the record. No unsupported pseudocode in this document is presented as callable Symblic syntax.
