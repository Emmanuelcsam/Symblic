The author supplied objectives, finite test cases, orchestration and an independent Python Fraction oracle. No candidate code was hand repaired.

The [model-written solver](solver.js) distinguishes a unique solution, an underdetermined singular system and an inconsistent system. [Nineteen synthetic systems](cases.json) cover dimensions one through three, row swaps, fractional and negative solutions, and all three classifications. Native checks additionally cover determinant signs and singularity, non-leading rectangular minors, rank-zero through rank-three cases, fraction normalization and frozen inputs.

For example, the system `2x+y-z=8`, `-3x-y+2z=-11`, `-2x+y+2z=-3` gives `x=2`, `y=3`, `z=-1`. These finite checks do not establish arbitrary matrix size, numerical range, overflow handling or general model capability. The solver uses integer determinants and returns exact numerator/denominator pairs. Its independent Python oracle uses Fraction Gauss-Jordan elimination, a different algorithm.
