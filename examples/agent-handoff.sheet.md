# handoff.js

## Shared

Integer arithmetic. Define only the names requested by each unit.

## Unit `double(x)`

Return twice the integer x.

Examples:
    double(3) ==> 6
    double(-2) ==> -4

## Unit `ready()`

Return the string "ready".

Examples:
    ready() ==> "ready"

## Unit `next(x)`

Uses: `double`

Return double(x) plus one.

Examples:
    next(3) ==> 7
    next(-2) ==> -3
